# 💱 Real-Time Currency Converter

An interactive, responsive real-time Currency Converter web application built using **Vanilla JavaScript**, **HTML5**, and **CSS3**. It fetches live foreign exchange rates and automatically updates national flags corresponding to selected currencies.

---

## 🚀 Live Demo & Preview

> **Live Preview:** Open index.html directly in any web browser or deploy with GitHub Pages.

### ✨ Key Features
- **Live Exchange Rates:** Integrates with @fawazahmed0/currency-api for real-time forex exchange rates across 150+ global currencies.
- **Dynamic Country Flags:** Automatically updates country flags in real-time as currencies are switched via FlagsAPI.
- **Default Conversion:** Pre-configured with popular conversion pairs (USD to INR).
- **Interactive UI:** Clean, mobile-responsive card layout with intuitive select dropdowns and validation.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3
- **Scripting:** Modern JavaScript (ES6+ sync/await, Fetch API, DOM Manipulation)
- **APIs Used:**
  - [Currency API](https://latest.currency-api.pages.dev) (Live exchange rates)
  - [FlagsAPI](https://flagsapi.com) (Dynamic 64px flag icons)
- **Icons:** Font Awesome 7.0
